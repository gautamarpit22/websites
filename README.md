# Websites

Cinematic scroll-driven websites built with AI-generated hero films. Plain HTML, CSS and vanilla JavaScript. No frameworks, no build step.

| Site | Live | Folder |
|---|---|---|
| OUVRAGE — luxury leather maison | https://ouvrage.designhivehq.com | `site/` |
| GiggleGrain — kids' food store | https://gigglegrain.designhivehq.com | `kidsfood/site/` |
| SOLÉA — ladies' footwear store | https://solea.designhivehq.com | `solea/site/` |

Each site is one `index.html` plus an `assets/` folder. The hero video scrubs with scroll on desktop; phones get a designed still cover. GiggleGrain and SOLÉA include a cart and WhatsApp checkout.

All brands are fictional design pieces. All imagery is AI generated.
