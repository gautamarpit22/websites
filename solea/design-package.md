# SOLÉA — Design Package (choreographed store build)

## Brand premise
SOLÉA, maison de souliers. Invented premium ladies' footwear house. Promise: beautiful shoes that don't hurt. Voice: confident, lightly French, warm. Footer discloses fiction. Budget cap 250 credits (user-approved). Projected ~190.

## The one call to action
Add to cart → Order on WhatsApp (placeholder +910000000000 until user sends number). Size-exchange promise beside every buy moment: "Sized true. Exchanged free."

## Customer language (research)
- Pain: "gorgeous but killed my feet", 62% of heel wearers report foot pain, blisters, "can't last past dinner".
- Desire: heels that feel like sneakers, flats with real cushioning, all-day wear.
- Online objection: wrong size fear → free size exchange, true-to-size promise.
